name: hash_cracker
description: Crack a hash you are authorised to crack, offline, on this machine. Identifies a hash by shape, converts a capture file into hashcat's modern WPA mode 22000 (or the older hccapx), lists the wordlists this machine already has, and starts a hashcat or John session that reports back its real speed and progress. Every crack runs on a file that is already here: no hash is uploaded, no server is contacted, and a missing tool is named with the package that provides it.
