name: wireless_audit
description: Audit a wireless network you own or have written permission to test: inventory interfaces and monitor-mode capability, survey visible access points, capture a WPA handshake or a PMKID with the aircrack-ng suite, wifite2, bettercap or hcxdumptool, run a WPS audit with reaver/bully, or - only behind an explicit policy rule - stand up a rogue AP. Every operation needs an explicit target and an explicit authorisation, and each result states which tool it used, whether that tool is installed, and what this machine's adapter can actually do. Never runs against an interface or access point the caller did not name.
